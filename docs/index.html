Visual storytelling pipeline

From article URL to visual story concept.

DataForPeople extracts the core tension from a public article, creates a visual metaphor, generates image variants, and routes the result through a PaperBanana-inspired critic loop and quality gate.

Pipeline

Each step keeps the source meaning attached to the image.

01

Ingest

Fetches source text and extracts headline, facts, numbers, tone, and core tension.

02

Concept

Creates a visual metaphor and prompt from the structured source summary.

03

Generate

Produces three 16:9 image variants with the Hugging Face Inference API.

04

Review

Uses a critic loop and final quality gate to choose publish or human review.

Critic loop

The generated image is checked before it is treated as usable.

A

PaperBanana pattern

The project uses the Visualizer-Critic idea from PaperBanana: generate an image, inspect it, revise the prompt, and regenerate for a small number of rounds.

B

What the critic checks

The critic receives the image, source facts, visual metaphor, and core tension. It checks whether the image shows the facts and whether the meaning is readable without a caption.

C

Prompt refinement

If the visual misses the point, the critic writes a refined prompt and the system generates a new set of variants.

D

Best round kept

The app keeps the best-scoring round instead of blindly using the final regeneration, because later prompt edits can sometimes make an image worse.

Run locally

The backend needs local API keys and cannot run on GitHub Pages.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

Open http://localhost:8000, enter Gemini and Hugging Face keys, then paste a public URL.
